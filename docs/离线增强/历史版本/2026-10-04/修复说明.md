# homr 确定性缺陷修复与离线增强

本轮依据任务 `01a1016c-4637-73c2-946f-298085d0af24` 的测试产物，修复能够复现的实现错误。没有重新训练模型，也不承诺所有图像均识别正确。琴键漫游 / PianoRoam 应用内后端保持原样，增强版作为独立、可复现的本地工具交付。

## 修复内容

|问题|修复后的行为|
|---|---|
|谱号与音符混组触发零时值断言|谱号作为属性保存，和弦音符保持同刻；不把谱号转换为休止符。|
|前反复、房子结束符制造空小节|前反复放在左侧，结束符归属实际音乐小节，后续音符保持正确小节位置。|
|连续小节线后后反复归属错误|后反复与后反复接前反复的边界正确附着于前后音乐小节。|
|多小节休止符只有样式、没有时序|按当前拍号展开 N 个整小节休止符，保留样式与前后音乐；冲突计数或不可表示的时值定位报错。|
|`rest_3m` 被当三连音并改成 `rest_2m`|多小节休止符不参与连音分类及清理，小节数量保留。|
|复声部推断拍长与导出时钟不同|使用持续音的实际结束时刻计算小节长度；不同拍号 token 区域分别推断，补全连音的正常类型与附点。|
|混组的矛盾小节线制造全页错位|矛盾混组保留原 token 与位置作为未解析提示；独立控制符号保留原结构解释，避免过严校验移除真实边界。|
|布局推断裁去首尾谱表、空谱表被跳过|明确报错并定位系统、声部和纵坐标，阻止部分识谱被标成完整成功。|
|解码到长度上限仍返回部分乐谱|未生成结束 token，或输出含 NaN/Inf 时明确失败。|
|吞掉异常且返回成功|单页错误传播，目录部分失败返回非零退出码；保留日志、部分输出及失败状态。|
|失败重识别删除旧 XML、合并写入源码目录|采用同目录原子写入，失败保留旧结果；合并写在输入旁，并保留各页结果。|
|标题 OCR 失败阻止音乐导出|记录标题错误后保留音乐结果。|
|连音清理日志不能证明实际改动|仅对真实变更写 JSON，包含小节、符号序号、完整原始与修改 token 及原图坐标；无改动不报删除。|

运行包核验固定源码、模型、补丁及镜像，推理断网。基本 XML 结构、无输出、超时及引擎失败分别记录。输出目录须为新目录，运行中断及重试保留版本证据，报告拒绝混用不同补丁。

## 已知边界

- 公开谱三连音仍可能漏识，声部分类也可能错误。短小节三连音清理的启发式存在反例：合法弱起或变拍号小节可能被误改。本轮保留实际修改证据，未盲目禁用该算法。
- 模型 token 只编码拍号分母；同分母的拍号分子变化不能可靠恢复。多小节休止的时值依赖当前推断拍号，诊断日志明确记录这一依据。
- 礼貌变音、连线类别、装饰音和部分印刷符号仍有模型或表示能力限制。XML 的实际音高变化与原图是否印刷某个临时记号是不同信息。
- 核心 F1 为音高、拍位置、时值匹配指标，不能当作整张谱完全正确率。新增正常连音类型属于可用信息，但参考 XML 未写该可选字段时，冻结的成分分数可能下降；逐页下降列表保留。
- 日志回放验证导出器，不包含新模型推理；缺陷病例的真实推理回归不代表全部公开谱或独立作品的总体水平。
- 本轮没有执行 琴键漫游 / PianoRoam 应用内后端替换、打包分发、完整 UI、人工谱面或真实 USB MIDI 验收。
