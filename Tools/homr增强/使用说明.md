# 原始增强包复现工具

此目录保留 2026-10-04 原始增强版的补丁、版本锁、源码准备器、严格 Docker 运行器及其聚焦测试。当前仓库根目录已移植到较新的上游代码，不再与这份历史版本锁逐文件相同。

完整使用方法见[离线增强使用说明](../../docs/离线增强/使用说明.md)。原始增强包与模型由 GitHub 发行附件提供，历史谱图、评分语料、运行输出和训练恢复备份保留在原项目本机目录，未混入本仓库。

运行工具自检：

```sh
python3 Tools/homr增强/运行工具测试.py
```

若本机保有原实验的固定 Docker 镜像，可对下载的原始包运行：

```sh
python3 Tools/homr增强/运行.py \
  --source /绝对路径/homr-enhanced-20261004 \
  --input /绝对路径/乐谱.png \
  --output /绝对路径/本次新输出目录 \
  --timeout 600
```

输出目录必须不存在；每次识别保留输入、日志、原始 MusicXML、退出状态和运行元数据。重新运行需另选目录。成功仍要求人工对照原谱。
